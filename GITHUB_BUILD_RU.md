# Сборка AIMP Karaoke Studio на GitHub (без инструментов разработки на компьютере)

**Это архив с исходным кодом. Готовый .aimppack создаётся только после успешного GitHub Actions workflow.**

## Самостоятельно через браузер

1. Войти в https://github.com и открыть https://github.com/new.
2. Создать репозиторий, например `aimp-karaoke-studio`. Вариант **Public** использует бесплатные стандартные Windows runners. Не добавляйте README при создании (он уже в архиве).
3. Распаковать этот ZIP на своём компьютере (компилировать ничего не нужно).
4. Открыть созданный репозиторий -> `uploading an existing file` / `Add file` -> `Upload files`.
5. Перетащить **всё содержимое распакованной папки**, включая скрытую `.github`, в браузер. В корне GitHub должны появиться `.github/`, `app/`, `plugin/`, `tests/`, `build.ps1`.
6. Нажать `Commit changes`. При `push` запустится Windows workflow. Если он не появился, открыть вкладку Actions, разрешить Actions, выбрать `Build Windows installer (x64)` и нажать `Run workflow`.
7. По завершении открыть Actions -> нужный запуск -> `Artifacts` -> скачать `AIMP-Karaoke-Studio-x64-installer`.
8. Скачанный GitHub-артефакт может быть ZIP-контейнером. Распаковать его и установить содержащийся `AimpKaraokeStudio-x64.aimppack` в AIMP -> Настройки -> Плагины -> Установить.

## Если сборка завершится красным

Это **ещё не проверенный на Windows исходный проект**. Ошибки MSVC или WPF могут проявиться впервые. Передайте ссылку на Actions run или текст ошибки в ChatGPT — тогда по логам можно исправить исходники и повторить сборку. Зелёный workflow подтверждает сборку и тесты, но **не означает, что интеграция с установленным AIMP была протестирована**.

## Вариант с минимальным участием пользователя

Создайте пустой репозиторий и предоставьте доступ к нему подключённому GitHub-плагину в ChatGPT, затем пришлите ссылку. Ассистент сможет попытаться загрузить исходники и проанализировать CI в пределах разрешений GitHub-плагина. Пароли и personal access tokens в чат отправлять не нужно.
