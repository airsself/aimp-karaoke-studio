# Design QA — матрица приёмки WPF v1

**Автоматический уровень:** `python tests/design_system_checks.py`, `python tests/source_contract_checks.py`, WPF/LRC regression, Windows x64 build.

**Визуальный уровень:** выполняется на реальном Windows-десктопе с AIMP 5.40 x64. Отмечайте `PASS / FAIL`, при FAIL приложите скриншот, разрешение, DPI, воспроизводимый сценарий и SHA коммита.

## Предусмотренные проверки CI

- Разбор пяти XAML-файлов (App, MainWindow, SearchWindow, Tokens, Components).
- Отсутствие дублирующихся и несуществующих `StaticResource` / `DynamicResource`.
- Совпадение JSON-дизайн-токенов с runtime XAML, геометрии с C#.
- Контраст стандартных текстовых пар ≥ 4.5:1 (WCAG relative luminance).
- Шаблоны состояний `hover/focus/selected/disabled`.
- Сценарий реального WPF поиска с **production** ResourceDictionary вместо заглушек.

## Решение о релизе

Успешный CI означает отсутствие известных синтаксических и автоматизированных регрессий. Пометку **visual QA passed / production design validated** можно ставить только после ручного прохождения сценариев 01–20. Особенно важны кастомный шаблон ComboBox, клавиатурный фокус и 150–200% DPI.
