# AIMP Karaoke Studio v0.3 — результат исправлений после аудита

**Исходная версия:** v0.2. **Новая версия:** v0.3 (исходный код для Windows-сборки). Исходная v0.2 оставлена без изменений.

## Основные изменения

1. Установочный пакет теперь учитывает структуру AIMP x64 (`AimpKaraokeStudio/x64/`). Есть отдельный валидатор пакета.
2. Асинхронные запросы Lyrics Service и AlbumArt Service теперь отслеживают task handle, отменяются через SDK с флагом ожидания и учитывают уже работающие callbacks. Это важная мера защиты от выгрузки DLL во время ответа, но доказать безопасность можно только тестом AIMP на Windows.
3. Данные IPC ограничены по размеру; вместо циклического разрыва соединения отправляется сообщение об ошибке. Команды идут через очередь без повторного выполнения.
4. Новая песня маркируется generation. События позиции, состояния, текста и обложки проверяются по поколению.
5. Парсеры LRC на C++ и C# применяют `[offset:]` ко всему тексту, объединяют двуязычные строки с одинаковым временем, принимают UTF-8 и UTF-16. Для legacy LRC поддержан Windows ANSI fallback.
6. Подсветка больше не остаётся на строке после `EndMs`. Обычные тексты отображаются с полным выбранным размером шрифта.
7. В WPF используется виртуализируемый список, обновление оформления во время проигрывания ограничено соседними строками. Доработаны manual scroll, возврат к текущей строке, настоящий межстрочный интервал в переносах, поведение полноэкранного окна и восстановление позиции.
8. Добавлен приём обложки через AIMP AlbumArt Service (при наличии PNG/JPEG-encoded container до 450 кБ); локальные JPEG/PNG загружаются в фоне.
9. Процессы UI различаются по идентификатору AIMP/именам pipe и защищены mutex от повторного запуска.
10. Добавлены тесты на C++/C#, Windows CI, changelog, лицензия, логирование и техническая документация.

## Проверка текущей среды

- **C++ LRC:** 7 сценариев успешно, включая `[offset:]` после текста и одинаковые timestamps; компиляция `clang++ -std=c++20 -DNDEBUG -Wall -Wextra -Wconversion -Werror` успешна.
- **CMake/CTest:** один тестовый исполняемый файл, тест пройден.
- **Статическая проверка WPF:** XML/XAML/CSProj корректны, ресурсы, имена и обработчики событий находятся; 15 source contract checks пройдены.
- **C# LRC:** исходник 7 дополнительных тестов написан, не запускался (нет .NET 10 SDK).
- **Windows MSVC/WPF:** пока не компилировались (нет Windows и Visual Studio).
- **AIMP-плагин:** ещё не запускался в установленном AIMP.

## Оставшиеся обязательные проверки перед релизом

**Не считать проект протестированным бинарным релизом.** На Windows с AIMP 5.40 необходимо подтвердить: cancellation callback tasks при закрытии и быстрой смене треков; доставку команд при остановленном/приостановленном плеере; семантику `AIMP_LYRICS_PROPID_OFFSET`; формат AlbumArt imageContainer; мультимониторное DPI/полноэкранный режим; профилирование больших LRC и работу установленного x86/x64-пакета. Подробности — `docs/REMEDIATION_REPORT.md` и `docs/TEST_PLAN.md`.

## Сборка

```powershell
.\build.ps1 -SdkDir 'C:\AIMP-SDK\Sources\Cpp' -Architecture x64
python tests/verify_package.py 'dist/AimpKaraokeStudio-x64.aimppack' x64
```

Примечание: команде нужен реальный официальный SDK AIMP, Visual Studio C++ и .NET 10; ZIP с исходниками *не* является готовым `.aimppack`.
