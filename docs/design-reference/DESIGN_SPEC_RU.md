# AIMP Karaoke Studio — дизайн интерфейса v1

**Назначение:** отдельное изменяемое по размеру окно для чтения и исполнения текста песни, синхронизированное с AIMP. Этот пакет содержит **дизайн-прототип**, не DLL и не готовый плагин.

## Визуальный источник

Предоставленный пользователем скриншот AIMP. Мы наследуем визуальный язык плеера, **не копируем** его медиатеку и плейлисты в дополнительное окно.

| Токен | Значение | Применение |
| --- | --- | --- |
| Main background | `#101011` | Рабочая область текста |
| Chrome | `#161618` | Заголовок, нижний транспорт |

Сохранены характерные для AIMP тонкие границы, компактные элементы управления, цвет активного состояния, плотная типографика Segoe UI, сдержанный контраст. Без web-dashboard, ярких градиентов, карточек или разноцветных декоративных элементов.

## Структура окна

1. **Заголовок, 38 px:** название окна и минимальные Windows-контролы.
2. **Компактный трек-бар, 70 px:** миниатюра обложки, исполнитель/название, переключатель «Чтение / Караоке / Сцена», кнопка настроек.
3. **Область текста:** максимальная площадь, фиксированная зона внимания на ~46% высоты; окружающие строки приглушены, активная строка увеличена.
4. **Нижняя панель, 64 px:** воспроизведение, временная шкала, изменение размера текста, полноэкранный режим, импорт LRC для демо.
5. **Панель настроек, 298 px:** скрыта по умолчанию, появляется справа, не перекрывая элементы управления AIMP.

## Три режима

- **Чтение:** вертикальная лента со всем текстом; акцент в районе центра. Для спокойного подпевания.
- **Караоке:** рядом с текущей строкой видны только ближайшие строки; быстрый поиск следующей строки.
- **Сцена:** только текущая и следующая строка, увеличенный шрифт; удобно для просмотра на расстоянии.

## Управление и доступность

- **Размер текста:** 24–100 px в макете; Ctrl +/- и A-/A+.
- **Межстрочный интервал:** 1.1–2.0.
- **Контраст соседних строк:** 15–95%.
- **Смещение синхронизации:** ±2000 мс с шагом 50 мс.
- **Атмосфера от обложки:** 0–40% (по умолчанию 10%).
- **Цвет:** 4 приглушённых акцента, фиолетовый AIMP по умолчанию.
- **Space** — воспроизведение/пауза, **Alt ←/→** — смещение на 100 мс, **F11** — полный экран, **Esc** — закрытие настроек.
- Анимации можно отключить системной настройкой «уменьшение движения».

## Что проверено

- Интерфейс открыт в headless Chromium из исходного HTML.
- Все 10 демонстрационных строк отрисовались, определена активная строка.
- Переключение режима и открытие настроек выполняются без ошибок JavaScript.
- Изменение размера текста 42 → 62 px проходит, без перезагрузки.
- Созданы скриншоты режимов с закрытыми и открытыми настройками.

## Граница между дизайном и реализацией

Демонстрационное время воспроизведения — **симуляция**. Тексты в макете — авторские тестовые строки, а не реальные тексты музыкантов. Само приложение AIMP здесь не управляется. После согласования внешнего вида разметка и графические токены могут быть перенесены в WPF/Windows-плагин.
